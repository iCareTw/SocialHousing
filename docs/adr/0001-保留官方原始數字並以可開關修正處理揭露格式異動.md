# 保留官方原始數字，以可開關的修正處理揭露格式異動

政府不定期變更社宅進度的揭露格式（合併/拆分進度分類、將既有併入或拆出完工欄位等）。我們決定 `data.json` 只存各期官方原始公告的數字，跨期修正一律在顯示時以可開關的選項套用，且預設關閉。如此每一期都能與官方 PDF 逐期對帳，修正方式日後改變也不必重整歷史資料。

## 既有的補值（含估算）

官方只有 202303～202411 與 202610 起單獨揭露既有，其餘期間的既有戶數由我們補上：

- **202302 以前**：早期格式為逐案揭露（例如 `data/pdf_SocialHousing/10810.pdf`），且不含既有。以 202303 首次揭露的既有戶數往回套用，屬估算。
- **202412～202505**：既有併入完工欄位，當時尚未開始抄寫，沿用 202411 最後一次揭露的戶數，屬估算。
- **202506～202609**：從 [全國社會住宅個案興辦執行情形](https://pip.moi.gov.tw/V3/B/SCRB0507.aspx) 的各縣市頁面（例如 `SCRB0505.aspx?city=臺北市`，各分類需點選後由 JS 渲染）人工抄寫。該網站沒有歷史版本，只能每月定期抄寫，抄錯或漏抄都無法回頭查證。
- **202610 起**：官方重新揭露既有，暫停抄寫與補值。這只是目前的揭露狀態，若日後官方再次把既有併入已完工揭露，就得恢復抄寫並重新補值。

## 分類異動

- 拆分只依政府其他公開資料推算（例如日後以另一份揭露資料拆回興建中與已決標待開工）。
- 不把歷史資料往回合併，例如不將 202610 以前的已決標待開工併入興建中，因為那會讓揭露程度變差。

## 用語

本站的「已完工」不含既有（見 `GLOSSARY.md`），畫面以「已完工」顯示；`data.json` 保留官方欄位值「新完工」。開關關閉時，部分期間的已完工會內含既有，需勾選既有社宅調整才符合本站定義。

## 維護方式

期間別差異目前分寫在 `Calculator.ts`（期間判斷與數值）與 `Descriptions.tsx`（說明文字），每次格式異動兩處都要更新。若異動變得頻繁，再抽成一份兩者共用的揭露期間表。
