# pip.moi.gov.tw「全國社會住宅個案興辦執行情形」作為已決標待開工資料來源的調查

調查日期：2026-11-16（台灣時間 23:30 前後）。比對對象：官方 PDF `data/pdf_SocialHousing/11510.pdf`（截至 2026/10/31）與 `src/components/SocialHousing/data.json`。

## 摘要

1. **資料從哪載入**：五個分類（總表、既有、新完工、興建中、已決標待開工）全部在 `GET SCRB0505.aspx?city=<縣市>` 的初始 HTML 裡，點分類只是用 JS 切換顯示，沒有額外請求。不必點選，一個 GET 就能拿到該縣市全部案件。另有「下載PDF」是 ASP.NET postback，可用 curl 重放。
2. **縣市涵蓋**：22 個縣市都有頁面，與官方 PDF 的 22 縣市一致。逐案有「興辦主體」欄，可區分中央（`中央(住都中心)`、`中央(財政部國有財產署)`）與地方（`○○市政府`／`○○縣政府`）。
3. **對帳**：網站是逐案資料。但**與 202610 PDF 對不上**：全國「網站興建中＋已決標待開工」86,704 戶 vs PDF 興建中 81,227 戶，表列 32 個縣市×興辦主體組合中 24 個不一致。原因是網站資料停在 **2025/05/31**：網站逐案加總與 `data.json` 的 202505 在 7 區×中央地方×3 分類共 42 格**完全一致**。
4. **更新時間**：總覽頁標示「截至114年5月31日生活圈戶數」；縣市頁沒有日期標記。網站本身沒有查歷史月份的功能。Wayback Machine 只有零星快照，2026 年的快照多為 WAF 擋掉的錯誤頁。
5. **抓取限制**：robots.txt 寫了 `Disallow：/V3/`（整個 `/V3/` 路徑都在禁止範圍，雖然冒號用的是全形「：」）。本次 23 個 GET（間隔 4 秒）都沒有驗證碼或被擋；資料不需要 cookie，PDF postback 需要 ViewState 等隱藏欄位。前端有 F5 類 WAF（`TS01…` cookie、「Request Rejected / support ID」錯誤頁）。

## 1. 各分類資料的請求

### 觀察方式
用 Playwright 開 `https://pip.moi.gov.tw/V3/B/SCRB0505.aspx?city=臺北市`，記錄網路請求，再點「下載PDF」。

### 能否不點選直接取得
可以。`curl` 直接 GET 即回傳完整 HTML（含五張表），不需要先取 cookie、不需要 JS。

### 觀察到的可重放請求範例

資料（GET）：
```
GET https://pip.moi.gov.tw/V3/B/SCRB0505.aspx?city=%E8%87%BA%E5%8C%97%E5%B8%82
→ 200, text/html; charset=utf-8, 226,885 bytes
```

下載 PDF（ASP.NET postback，瀏覽器實際送出的格式）：
```
POST https://pip.moi.gov.tw/V3/B/SCRB0505.aspx?city=%u81fa%u5317%u5e02
Content-Type: application/x-www-form-urlencoded
__EVENTTARGET=&__EVENTARGUMENT=&__VIEWSTATE=<GET 回來的值>&__VIEWSTATEGENERATOR=<同>&__VIEWSTATEENCRYPTED=&__EVENTVALIDATION=<同>&hfCity=臺北市&hfMode=總表&btnPN2_ExportPDF=下載PDF
→ 200, application/pdf, Content-Disposition: attachment;filename=社會住宅興辦案件執行情形彙整表_臺北市_總表.pdf
```
- `hfMode` 決定匯出哪個分類（總表／既有／新完工／興建中／已決標待開工）。
- 用 curl 重放：先 GET 取隱藏欄位與 cookie，再 POST，`hfMode=興建中` 成功拿到 4 頁 PDF。第一次漏帶 `__VIEWSTATEENCRYPTED`（並用 UTF-8 編碼的 action URL）時，回傳 200 但內容是「錯誤訊息」HTML 頁。
- 匯出的 PDF 由 wkhtmltopdf 0.12.2.4 產生，內容與網頁表格相同，非另一份資料。其 metadata `CreationDate` 兩次都是 `2026-04-07 11:35`，與實際請求時間（2026-11-16）不符，原因未確認。

## 5. 抓取限制

- **robots.txt**（`https://pip.moi.gov.tw/robots.txt`，`last-modified: Fri, 28 Aug 2026`）：

  ```
  User-agent：*
  Disallow：/Backstage/
  Disallow：/MBS/
  Disallow：/Eng/
  Disallow：/V3/
  Disallow：/Publicize/DigitalArchive/SessionTest
  …（其餘為 /Publicize/… 路徑）
  ```
  `/V3/` 在禁止清單內，`SCRB0505.aspx` 與 `SCRB0507.aspx` 都在 `/V3/B/` 下。檔案中的冒號是全形「：」（位元組檢查確認），嚴格的 robots.txt 解析器可能認不得，但網站的意圖是禁止自動抓取 `/V3/`。
- **頻率限制／驗證碼**：本次共 23 次 GET（總覽＋22 縣市，間隔 4 秒）與 2 次 PDF postback，全部正常回應，沒有驗證碼、沒有 429。更高頻率的門檻未測試（未確認）。
- **WAF**：每個回應都 `Set-Cookie: TS01e1f903=…; Domain=.pip.moi.gov.tw`，且 Wayback 存到的錯誤頁是「The requested URL was rejected. Please consult with your administrator. Your support ID is: …」。這兩項是 F5 BIG-IP ASM 常見特徵（推測，未向管理單位確認）。Internet Archive 的爬蟲在 2026 年被擋，代表此 WAF 會拒絕部分自動化請求；本次 curl 未被擋，判斷規則未確認。
- **cookie／session**：GET 資料不需要任何 cookie。PDF postback 需要先 GET 取得 `__VIEWSTATE`、`__EVENTVALIDATION` 等欄位（並帶上 GET 時拿到的 cookie；不帶 cookie 是否可行未測試）。
